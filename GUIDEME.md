# Guide — Blog Writing App

**Live:** https://blog-writing-app-ashy.vercel.app

## Prerequisites

- Python 3.10+ (for Python projects) / Node.js 18+ (for Next.js projects)
- Git

## Setup

```bash
# Clone the repository
git clone https://github.com/keerthishree20/blog-writing-app.git
cd blog-writing-app
```

## Running the App

```bash
npm install
npm run dev
```
App runs at `http://localhost:3000`

### Environment Variables
Copy `.env.example` to `.env.local` and fill in your values.
